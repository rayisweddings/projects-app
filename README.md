# RAYIS Projects — desktop app

The RAYIS Weddings Project Tracker in its own window, for Mac and Windows.

**Download:** https://rayisweddings.com/projects-app

It's a thin shell over the live tracker at rayisweddings.com/hq/projects, so
new features arrive with the website — the app itself rarely needs updating.
Sign in with your RAYIS HQ email and password; the sign-in is remembered.

This repository holds the installers only (see Releases).
